基本信息 #

企业名称：沃尔核材

股票代码：002130

所属版块：中小板

一级市场名称：信息技术

二级市场名称：电子

三级市场名称：其他电子

四级市场名称：其他电子

关注度：⭐⭐⭐⭐

笔者自2021年起便开始关注沃尔核材。在5月份刚开发完一套选股系统后，即进行了初步布局，同时也关注了东方电缆。彼时，投资尚处于试验阶段，大部分资金投入于东方电缆。在其股价翻倍并获利了结后，笔者逐步加仓沃尔核材，并持仓至2022年8月份，成本价约为8元。尽管未能坚持持有至2024年的25元，但这并未影响笔者的选股思路。

主营业务分析 #

沃尔核材的主营业务涵盖多个领域，主要包括电子系列产品、电力系列产品、电线系列产品及新能源系列产品，展现出强大的市场竞争力和技术创新能力。

1. 电子系列产品 #

沃尔核材的电子系列产品主要包括聚烯烃单壁管、双壁管、母排管、标识管以及氟化物和弹性体等热缩套管。这些产品具备收缩方便、耐高温、阻燃、防腐及无卤环保等优良特性，为电线、电缆及电气设备提供了卓越的绝缘防护功能，广泛应用于电子、电器、通讯及汽车等多个领域。

公司在国内市场占据了较大的份额，尤其是在电器和电子元器件的传统领域。随着国内产业结构的升级和国际产业转移的加速，以及国产化替代的推进，沃尔核材在高端领域的市场份额将持续提升，尤其是在汽车电子、轨道交通、航空及核电等领域，已取得显著突破。

2. 电力系列产品 #

沃尔核材的电力系列产品包括电缆附件、线路金具、环氧绝缘制品及绝缘防护制品等。这些产品具备施工便捷、绝缘强度高及性能可靠等优点，广泛应用于发电、配电、成套设备、轨道交通及石油化工等领域。电力行业对企业资质及产品质量要求较高，产品需求主要通过招投标等方式进行。

公司在国内市场保持了相对稳定的市场份额，未来将加快高压、风电、光伏及功能型电缆附件的开发，以满足国家能源转型及智能电网新体系的建设需求。

3. 电线系列产品 #

沃尔核材的电线系列产品主要包括高速通信线、汽车工业线及工业机器人线等。公司重点关注高速通信设备、乘用车及新能源汽车、工业及医疗等核心市场。电线产品已从电子消费领域逐步转型至高速通信、汽车传输及工业自动化等应用领域，并取得显著成效。

随着行业整合加剧和规模化发展趋势的明显，细分高端领域的行业集中度将进一步提高，沃尔核材将继续聚焦重点产品线，提升产品性能与品质，扩大核心市场的销售份额。

4. 新能源系列产品 #

沃尔核材的新能源系列产品主要包括风力发电和新能源汽车业务。风力发电业务在报告期内平稳运行，青岛风电河头店、东大寨及河崖风电场总容量为144.2MW，2022年上网电量为2.83亿千瓦时，全部销售给国网山东省电力公司。

新能源汽车业务方面，公司提供电动汽车充电枪、车内高压线束及高压连接器等产品，直流充电枪在国内市场上具有较高的认可度和市场占有率。随着新能源汽车推广政策的实施及技术的不断创新，公司将持续推进技术和成本领先，提高产品的市场竞争力。

杜邦分析 #

沃尔核材自2020年以来的业绩表现稳健，ROE（净资产收益率）始终保持在10%以上。2022年，尽管沃尔核材的净利润同比增长7%，但由于总资产周转率及权益乘数的下降，导致当年ROE下降了0.73%。

自2019年以来，沃尔核材的净利润持续攀升。根据对2024年前三季度业绩的追踪，预计2024年净利润将继续创新高。

通过对各季度毛利率、净利润率及各项费用的分析，可以看出沃尔核材的毛利率始终高于行业四级市场的平均水平。

现金流分析显示，沃尔核材在2022年的经营活动现金流净额显著增加。现金流拆分结果表明，购买商品及接受劳务支付的现金显著减少，推测出沃尔核材的产能在口罩风控期间受到了明显影响。

根据沃尔核材2022年年报，经营活动产生的现金流量净额较2021年同期增加了25,930.6万元，同比增长42.47%。这主要归因于报告期内销售商品及提供劳务收到的现金增加，以及购买商品及接受劳务支付的现金减少。这表明沃尔核材当年处于去库存及缩减产能的状态，直接导致其总资产周转率的下降。

总结 #

综上所述，沃尔核材在过去几年的稳健表现及良好的财务指标，尤其是ROE和现金流的持续改善，显示出其在行业内的竞争力与潜力。尽管面临短期挑战，长期来看，沃尔核材的市场地位和投资价值依然值得关注。投资者应密切关注其未来的业绩表现及市场动态，以把握投资机会。
